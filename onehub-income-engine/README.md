# OneHub AI Income Engine — public-source watch

This is a **real, scheduled, read-only GitHub Actions bot**, not a cryptocurrency miner, an autonomous money generator, or proof of payout. It can be managed through GitHub's website on an Android phone.

It checks public official sources for: Bitcoin-funded GitHub bounties (Lightning Bounties), HackerOne public security programs and payment policy, TesterWork availability, Clickworker country/payment policy, and Bugcrowd public program listings. A separate existing `onehub-bounty-hunter` job examines up to 50 GitHub issue leads daily and checks for assignments and competing pull requests.

Every external lead is **unverified for funding, claim availability, country access, and automation rules** until independently checked. An issue listing is not a payment offer to you. Country appearance on a project-directory page is not a confirmed invitation.

To inspect: GitHub → Factory-repo → Actions → OneHub income opportunity watch → latest run → Artifacts → onehub-income-watch. Daily schedule 07:17 UTC; manual workflow dispatch available. No Google Play APK or computer is required.

**Deliberately not included:** Tor or dark-web scraping, unauthorized access, credential theft, benefit/coupon abuse, speculative crypto trades, mining with unowned hardware, fake identities, spamming PRs or vulnerability scanners, selling user data, deposit-requiring earning sites, private wallet key collection, bank/crypto transactions, personal social media, and spending. Only a user-authorised, in-scope security test could be conducted separately after reviewing a program's scope.

An external payment provider must be connected and funded by real accepted work before income or conversion is possible. A dashboard cannot confirm funds without a payout or bank/wallet transaction record. Do not enter seed phrases into bots.

Test: `python -m unittest discover -s onehub-income-engine -p 'test_*.py' -v`.
